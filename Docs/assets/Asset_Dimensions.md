# Asset Dimensions Guide

Base Character Size: **64x64 pixels**

To maintain a consistent scale relative to the character, resize your item images to the following recommended dimensions:

## Item Sizes

| Item | Recommended Size | Type |
| :--- | :--- | :--- |
| **Silver Dirhams** | **32x32 px** | Small Collectible |
| **Inkwell & Kalam** | **32x32 px** | Small Collectible |
| **Compass** | **32x32 px** | Small Tool |
| **Dates** | **32x32 px** | Small Food |
| **Leather Sandals** | **40x40 px** | Medium Item |
| **Water Skin** | **48x48 px** | Medium Item |
| **Holy Quran** | **48x48 px** | Medium Item |
| **Woolen Djellaba** | **50x50 px** | Large Item (Folded) |
| **Prayer Mat** | **50x40 px** | Large Item (Rolled) |
| **Oil Lamp** | **40x40 px** | Medium Tool |
| **Travel Documents** | **40x32 px** | Medium Paper |

## Platform Tiles

| Asset | Recommended Size | Note |
| :--- | :--- | :--- |
| **Platform** | **200x40 px** | Standard Platform |
| **Platform (Small)** | **100x40 px** | Short Hop |

## Backgrounds

| Asset | Recommended Size | Note |
| :--- | :--- | :--- |
| **Backgrounds** | **1280x720 px** | Full Screen (HD) |

> **Tip:** Use a tool like Paint.net, Photoshop, or an online resizer (ezgif.com) to resize the PNGs. Ensure you maintain transparency!
